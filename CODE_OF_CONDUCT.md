# Code of conduct

## Our standard

Participation in the 3D-CovDiffusion project should be respectful,
professional, and focused on reproducible research. Be constructive when
discussing methods, results, code, data, and attribution. Welcome questions
asked in good faith and distinguish evidence from opinion.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate disruption, publishing another person's private
information, plagiarism, or knowingly misrepresenting experimental evidence.

## Scope

This standard applies to repository issues, pull requests, reviews,
discussions, and other spaces where someone represents this project.

## Reporting and enforcement

Do not report conduct incidents in a public issue when doing so would expose
private or sensitive information. Contact the repository owner through the
contact method on their GitHub profile and request a private channel. GitHub's
own reporting tools may also be used for conduct that violates GitHub policy.

Repository maintainers may edit or remove content, close interactions, or
restrict participation when necessary to protect the project and its
participants. Actions are considered in proportion to the behavior and its
impact. No response time is guaranteed.
