# Security policy

## Supported version

Security fixes are considered for the current `main` branch. Older commits,
local modifications, third-party dependencies, and unpublished artifacts are
not covered by a support guarantee.

3D-CovDiffusion is research software. It has not been safety-certified for
production robotics or autonomous operation.

## Report a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting for this repository if it is enabled. If it is
not available, contact the repository owner through the contact method on their
GitHub profile and request a private reporting channel.

Include the affected commit or release, impact, minimal reproduction, and any
suggested mitigation. Never include access tokens, credentials, or private
datasets. No response or remediation time is guaranteed.

Incorrect metrics, failed experiments, configuration questions, and ordinary
reproducibility bugs are not security reports; use the bug issue template for
those cases.
